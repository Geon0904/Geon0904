1) Create a New Calendar
- Launch the app (java -jar CalendarApp.jar --gui).
- At the top-left, next to "Calendar:", click New Calendar.
- In the popup, type a calendar name and select a time zone from the dropdown.
- Click OK to create and automatically switch to your new calendar.
- The active calendar is always shown in the dropdown menu.

2) Switch Between Calendars
- Click the dropdown next to "Calendar:" at the top-left.
- Select any calendar from the list to switch.
- (The schedule view updates automatically.)

3) Add an Event
- Under Add Event on the left:
- Enter a Subject (required) and an optional Description.
- Choose the Date with the date picker.
- Set Start Time and End Time with the time pickers.
- Click Add Event.
- The new event will appear in the schedule view on the right.
- If input is invalid (e.g., end time before start time), a helpful error dialog appears.

4) Delete an Event
- In the Schedule View (right panel), double-click the event you want to delete.
- In the event dialog, click Delete (or "Delete Event") and confirm when prompted.
- The event will be immediately removed from the calendar and the schedule view will refresh.

5) Edit an Event
- In the Schedule View (right panel), double-click any event.
- An edit dialog appears, pre-filled with event details.
- Change any field (subject, description, start/end time).
- Click OK to save changes, or Cancel to discard.
- If input is invalid, a helpful error message will appear.

6) View Scheduled Events
- By default, the schedule view shows up to 10 upcoming events from today’s date.
- To change the starting date:
- Use the date picker next to "Show events from:" at the top of the schedule view.
- Click Refresh to update the list.

7) General Notes
- Status updates and errors are always displayed at the bottom of the window.
- All event times use the selected calendar’s time zone.
- You cannot add, edit, or delete events unless a calendar is selected (one is always active by default).
